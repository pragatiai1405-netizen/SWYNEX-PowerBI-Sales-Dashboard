# SWYNEX Internship Task 3 – Power BI Sales Dashboard

## Project Overview
This project presents an interactive sales dashboard created using Microsoft Power BI as part of the SWYNEX Data Analyst Internship.

## Key Performance Indicators (KPIs)
- Total Sales
- Total Quantity
- Total Orders
- Unique Customers
- Average Order Value

## Dashboard Visualizations
- Monthly Sales Trend
- Top 10 Countries by Sales
- Top 10 Products by Sales

## Interactive Filters
- Country
- Date / Year / Month
- Product

## Tools Used
- Microsoft Power BI
- DAX
- Online Retail II Dataset (2009–2010)
